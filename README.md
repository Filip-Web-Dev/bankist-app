Bankist App - Banking Web Application

Bankist is a functional web application simulating online banking, built with Vanilla JavaScript, HTML5, and CSS3.

Key Features
- User Authentication: Secure login using username initials and a PIN code.
- Real-Time Balance and Summary: Live calculation of account balance, total deposits, withdrawals, and accrued interest.
- Money Transfers: Instant internal money transfers between user accounts.
- Loan Requests: Simulated loan approvals based on deposit conditions.
- Account Closure: Ability to delete active user accounts.
- Transaction Sorting: Toggle sorting of movements by amount.

Tech Stack
- HTML5 and CSS3: Layout built using Flexbox and CSS Grid.
- JavaScript (ES6+): Advanced DOM manipulation and Array methods (map, filter, reduce, find, some, findIndex).

 Project Context
Developed to master core JavaScript concepts, modern DOM manipulation, and functional array processing techniques.
